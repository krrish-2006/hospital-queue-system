# BookMyDoctor

BookMyDoctor is a hospital queue and appointment management web application that helps organize patient flow and reduce manual queue confusion.

## Live Demo
https://hospital-queue-system-rose.vercel.app

## Tech Stack
- HTML
- JavaScript
- Node.js
- Express.js

## Features
- Patient queue management
- Doctor/patient flow organization
- Simple web interface
- Server-side logic using Node.js and Express

## How to Run Locally

```bash
npm install
node server.js
